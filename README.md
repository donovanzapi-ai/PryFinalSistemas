# pryFinalSistemas
En este repositorio subiremos los archivos de el proyecto.

Descripción general del proyecto
	Buscaremos generar una aplicación de citas con backend que permita a los usuarios registrarse, crear un perfil, descubrir mas perfiles con un sistema tipo swipe y entablar conversaciones entre matchs.
